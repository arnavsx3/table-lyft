# Changelog

## 0.1.0 - 2026-10-12

First TableLyft implementation, rebuilt independently of the earlier Wingman project.

- WXT Manifest V3 extension with React, TypeScript, Zod, Papa Parse, and Lucide.
- Explicit, main-frame HTML table selection with a shadow-root picker.
- Bounded merged-cell extraction with hidden/form/editable content exclusions.
- Full-tab workspace: configurable headings, unique column names, selection, filtering, natural sorting, pagination, reset, and discard.
- CSV downloads with UTF-8 BOM and configurable separators; spreadsheet TSV and escaped Markdown clipboard output.
- Default spreadsheet formula protection, local-only processing, session retention, and tab/document-bound one-use capture requests.
- 46 unit tests, six installed-Chromium scenarios, responsive screenshots, production-bundle checks, and GitHub Actions packaging.
- Architecture, workflow, development, testing, privacy, and scope documentation.

Brave native-toolbar verification and Excel/Sheets import checks remain manual release checks. No store listing or universal scraping support is claimed.
