# Roadmap

## 0.1: Prove The Core

- On-demand main-frame HTML table capture.
- Bounded, tested merged-cell extraction.
- Roomy workspace with preview, column controls, headings, filtering, and sorting.
- Local CSV/TSV/Markdown outputs and formula protection.
- Clear failures, temporary storage, and narrow/desktop verification.
- Documented permissions, privacy, and supported scope.

## Validate Before Expanding

Invite ten students, researchers, or spreadsheet-heavy workers to try real tasks. Record whether capture worked, how much cleanup remained, and whether they returned to the extension. Use volunteered feedback, not hidden telemetry. Existing demand for table exporters does not prove TableLyft will be adopted.

## Possible Later Work

Typed Excel exports, accessible ARIA grids, user-driven combination of snapshots, and saved per-site configurations. Each needs its own feasibility spike and tests. Cross-origin frames require a deliberate permission decision.

## Not Promised

Universal scraping, automatic pagination, paywall bypass, image/PDF extraction, AI reconstruction of missing data, cloud sync, and unattended collection. No subscription or monetization architecture until actual repeat usage supports it.
